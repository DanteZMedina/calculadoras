
# Reglas básicas 
1. La web debe ser full responsive, no debe nunca tener scroll horizontal. 
2. TODO ES PENSADO PARA MÉXICO - CDMX.
3. Los calculos siempren deben ser separados por "," para facilitar su lectura, por ejemplo: $5,000.00 MXN 
$37,000.00 mxn 
4. El tipo de letra debe ser roboto, calibri o Arial (la que se adapte mejor que no tenga patitas las letras para facilitar la lectura)

# Estructura 
1. El proyecto debe ser realizado con HTML, CSS, JavaScript 
2. Esta permitido el uso de React, vue, entre otros frameworks que puedan ayudar a estructurar facilmente la web y su contenido.  
3. Los datos no se guardaran por lo que no tendremos que utilizar una Base de Datos. 

# Calculos 
1. Los calculos deben ser siempre con la información más reciente que proporcione el gobierno de la ciudad de México; y especificarlo en alguna parte cuando se muestren los datos. 
2. Se debe consumir las tasas, y demás data desde páginas del SAT, DOF, Banxico, Bancos (BBVA, Santander, CitiBanamex, Banorte, entre otros).
3. Jamas se debe inventar ningún número ni suponer por tu propia cuenta, siempre pregunta cuando tengas duda. 
4. ISR se consume del SAT, DOF, Banxico, o el que aplique en ese calculo y momento. 
5. Iva por el momento se tiene en 16%, pero siempre usar el dato desde una fuente oficial y no usar datos duros en el código. 
6. IEPS: Debe ser consultado directo de fuente oficial y no usar datos duros en el código. 
7. Cualquier otro impuesto aplicable al servicio y/o Producto que se requiera debe ser consultado directo de una fuente oficial y no usar datos duros en el código.
